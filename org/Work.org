* Welcome to Gnorg :demo:
These are editable demo files. Run make run to use this project's org folder
instead of your saved Calendar Folder. The saved preference is not changed.
An installed launch still uses your usual folder. Open files from your previous
session may also appear, since open Org documents remain agenda sources.

Click a filename below the mini-calendar to open it. Toggle its checkmark to
include or exclude it from Agenda and Calendar.
The mini-calendar highlights the selected week and marks event dates with dots.

** Inline formatting
Try *bold*, /italic/, _underline_, +strikethrough+, =verbatim=, and ~code~.
Literal spans keep their contents unchanged: =*not bold*= and ~/not italic/~.

| Format     | Example          |
|------------+------------------|
| Bold       | *important*      |
| Italic     | /emphasis/       |
| Underline  | _remember_       |
| Strike     | +obsolete+       |
| Verbatim   | =literal text=   |
| Code       | ~print("hello")~ |

** Mouse interactions :editor:

** Keyboard tour
- Alt+h / Alt+l: switch between Files, Agenda, and Calendar.
- Alt+j / Alt+k: select files in the utility pane.
- Alt+Up / Alt+Down: move a heading's whole subtree among siblings.
- Alt+Left / Alt+Right: promote or demote a subtree.
- Ctrl+Alt+e: open the current saved file at the cursor in Emacs.
- In Agenda: d for one day, w for the week, f/b to navigate,
  . for the current day or week.
- Calendar shows a week; f/b navigate weeks and . returns to the current week.
- In Agenda or Calendar: mouse button 8 goes back and button 9 goes forward
  by the current day/week span.
- Date, tag, and STARTUP editors in Files open their popovers at the line end.
- In Files, Agenda, or Calendar: click the search icon or press Ctrl+f to search
  all Org headings by title, TODO keyword, tags/location, category, or file path.
  Search includes undated headings, hidden agenda files, and unsaved open buffers.
  Select a result (or press Enter for the first match) to open its source.
  Down/Up or C-n/C-p navigate results. TODO states use their bold Org colors.
  Escape or C-g closes search.
- In Agenda or Calendar: C-x C-s saves all modified files without leaving the view.
- In Agenda: click an item to select it, then click it again to open its headline.
- C-c a opens the agenda chooser; then a opens the built-in Agenda.

** Custom agendas :demo:
Below Files, the Agenda section has a + button for creating saved views.
Try a headline list with key w, title Work tasks, All tags work and TODO states
TODO. It includes undated tasks too. Use C-c a followed by w to open it.

Or create a Week agenda with Any tags work home to show dated items matching
either tag. All filter fields combine with AND; states and priorities match
any listed value. Empty fields match everything, including completed headings.
Tag filters use each heading's own tags rather than inherited parent tags.
Right-click a saved view to edit or delete it; Shift+F10 opens the same menu.
